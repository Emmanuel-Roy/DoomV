# The WAD

Put the **shareware `DOOM1.WAD`** (version 1.9, 4,196,020 bytes,
SHA-1 `5b2e249b9c5133ec987b3ea77596381dc0d6bc1d`) in this folder.

It is not committed. The shareware episode may be shared freely, but only
unmodified, and the build changes it: `tools/wadpack.py` makes a packed copy
in the build folder that fits the Pico 2's flash (see
[docs/MEMORY.md](../docs/MEMORY.md)).

DoomV ships the same file at `DoomV/tools/doom/doombuild/DOOM1.WAD`.
